## ⚡ Executive Summary

**Jogjacare** is an open-source, enterprise-grade digital health tourism and healthcare directory platform engineered specifically for **Daerah Istimewa Yogyakarta (DIY)**. Developed with **Laravel 11**, **Livewire 3**, and **Tailwind CSS**, the platform establishes a seamless digital bridge for domestic and international tourists to access accredited medical centers, locate emergency healthcare points near top tourist attractions, evaluate transparent medical procedure costs, and explore authentic traditional Javanese wellness therapies (*Jamu & herbal medicine*).

> [!NOTE]
> Originally conceptualized and architected as an academic milestone at **Universitas 'Aisyiyah Yogyakarta (UNISA)**, Jogjacare is now published as a commercial-grade open-source blueprint to advance national health tourism digitalization across Indonesia.

## ✨ Core Pillars & Capabilities

### 1. 🏥 Medical Care & Specialist Directory
- **Clinical Specialty Catalog**: Searchable index of general and specialized medical practices (cardiology, oncology, orthopedics, dental care) across Yogyakarta.
- **Accreditation & Standards**: Clear profiles indicating hospital standards (KARS / JCI certifications) and physician credentials.

### 2. 📍 Medical Points (Tourism Attraction Proximity)
- **Emergency Radius Mapping**: Instant identification of medical points within critical response distance of major cultural spots:
  - **Malioboro & Kraton Yogyakarta**: 24-hour pharmacies and rapid-response clinics.
  - **Prambanan Temple Complex**: Nearest emergency facility (RS Nur Hidayah, ~6 km).
  - **Parangtritis Beach**: Accessible tertiary care routing (RSUP Dr. Sardjito, ~7 km corridor).

### 3. 🏛️ Medical Centers (Hospital Hubs)
- **Comprehensive Institution Profiles**: Detailed overviews of premier regional hospitals including **RSUP Dr. Sardjito** (Yogyakarta's largest tertiary teaching hospital) and **RSUD Panembahan Senopati**.
- **Facility Specifications**: Accurate data on ICU capacity, diagnostic imaging (MRI/CT), international patient services, and ambulance hotlines.

### 4. 💰 Medical Cost Transparency
- **Procedure Estimates**: Transparent fee ranges for consultations, routine health check-ups, diagnostic scans, and elective procedures.
- **Intercity Comparison**: Empirical cost comparisons demonstrating Yogyakarta's cost-effective healthcare quality relative to Jakarta and Surabaya.

### 5. 🌿 Traditional & Alternative Medicine (Javanese Healing)
- **Authentic Jamu & Herbal Heritage**: Curated directory of heritage jamu makers and certified herbal practitioners.
- **Traditional Wellness Therapies**: Information on regulated Javanese therapeutic treatments (pijat tradisional, bekam, herbal detox) for restorative wellness travel.

### 6. 🎒 Curated Medical Tourism Packages
- **Wellness Retreat Bundles**: Curated packages harmonizing health check-ups with cultural tourism across Sleman, Bantul, Gunungkidul, Kulon Progo, and Kota Yogyakarta.

### Modular Monolith Engineering

Jogjacare is constructed as a high-cohesion **Modular Monolith** using `nwidart/laravel-modules`, delivering rapid server-side rendering with reactive Livewire components without the latency of heavy single-page application hydration:

```text
[ Client Layer ]        ──► Responsive Blade Views + Livewire 3 Components + Tailwind CSS
          │
[ Application Modules ] ──► MedicalCare, MedicalPoints, MedicalCenters, CostEstimator, Wellness
          │
[ Access Control ]      ──► Spatie Permission (Super Admin, Executive, Manager, Admin, Tourist)
          │
[ Data & Audit Layer ]  ──► MySQL 8.0 + Spatie Activitylog + Sqids ID Obfuscation
```

| Layer | Component | Technical Role |
| :--- | :--- | :--- |
| **Presentation** | `Blade & Livewire 3` | Reactive search, dynamic filtering, and interactive destination-medical maps. |
| **Module Orchestration**| `nwidart/laravel-modules` | Clean domain separation across healthcare directories, tourism packages, and user profiles. |
| **Access Control (RBAC)**| `spatie/laravel-permission`| Role-based segregation for Super Admin, Executive, Manager, Content Admin, and User. |
| **Data Integrity & Audit**| `spatie/laravel-activitylog`| Immutable audit trails tracking master data changes, clinic updates, and user activities. |
| **Security Hardening** | `sqids/sqids` | Obfuscates sequential database IDs to prevent URL scraping and enumeration attacks. |

## ⚡ Quickstart

### Prerequisites
- **PHP** >= 8.2 (extensions: `pdo`, `mbstring`, `intl`, `gd`, `xml`)
- **Composer** >= 2.6
- **Node.js** >= 20.0 and `npm`
- **MySQL** >= 8.0

### 1. Clone & Install Dependencies

```bash
git clone https://github.com/MasterPandaa/Jogjacare.git
cd Jogjacare

composer install
npm install && npm run build
```

### 2. Configure Environment

```bash
cp .env.example .env
php artisan key:generate
```

Configure your database settings in `.env`:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=jogjacare
DB_USERNAME=root
DB_PASSWORD=your_password
```

### 3. Run Database Migrations & Seeds

```bash
php artisan migrate --seed
php artisan serve
```

Access the Jogjacare platform at: **`http://127.0.0.1:8000`**
